# Steerloom

**Make agent work visible. Keep key decisions human.**

English · [简体中文](#简体中文)

Steerloom builds focused tools for managing and coordinating AI agents. We help people understand agent capabilities, follow implementation progress, and make informed decisions at key checkpoints.

We believe execution details can be delegated, while critical steps must remain understandable and controllable. Better collaboration with agents means clear goals, boundaries, impacts, and outcomes—with room for people to intervene and adjust course.

## What we focus on

- **Clear capabilities**: Understand which capabilities an agent is configured with, where they come from, where they apply, and what changing them may affect.
- **Understandable execution**: Connect plans, implementation steps, actual changes, and verification evidence so people can explain how the work takes shape.
- **Control at key checkpoints**: Make decisions and acceptance criteria explicit, reducing the need to watch every execution detail.

## Tools and directions

### Agent Lens · Current project

A workbench for agent configuration and capabilities. Agent Lens focuses on inspecting, analyzing, and managing Skills, Plugins, MCP, and custom sub-agents, making their sources, scopes, and the impacts of management actions clearer.

[Explore the Agent Lens repository](https://github.com/Steerloom/Agent-Lens)

### From plan to implementation · Planned

A tool for organizing plans into implementation steps by architectural layer or feature, guided by an existing project's engineering practices. It would show progress, affected areas, and relationships between steps, helping maintainers understand execution, identify deviations, and review milestones.

This direction is still being planned and has not been released as a product.

## Product principles

- **Start with specific problems**: Each tool addresses a clear management need and can be used independently.
- **Support judgment with evidence**: Distinguish known facts, inferences, and unverified states. A complete-looking picture should never hide uncertainty.
- **Keep people in control**: Make the evidence, implications, and available actions behind key decisions clear.

## 简体中文

**让执行可见，让关键决策在人。**

Steerloom 致力于打造一组聚焦具体场景的 Agent 管理与协作工具，帮助人理解 Agent 的能力、掌握实施进度，并在关键节点做出有依据的决定。

我们相信，执行细节可以委托，关键环节必须清晰可控。更好的 Agent 协作，需要让人看清目标、边界、影响与结果，并能在需要时介入和调整。

### 我们关注什么

- **能力清晰**：理解 Agent 配置了哪些能力、来自哪里、适用于什么范围，以及变更可能带来的影响。
- **过程可理解**：连接方案、实施步骤、实际改动和验证证据，让人能够讲清楚工作如何落地。
- **关键节点可控**：明确决策与验收标准，减少持续盯住执行细节的负担。

### 工具与方向

#### Agent Lens · 当前项目

Agent 配置与能力工作台，聚焦 Skills、Plugins、MCP 和自定义子 Agent 的查看、分析与管理，让能力来源、作用范围和管理操作的影响更清楚。

[查看 Agent Lens 仓库](https://github.com/Steerloom/Agent-Lens)

#### 方案到实施的管理工具 · 规划中

围绕现有工程规范，将方案组织为按层次或功能划分的实施步骤，呈现节点进度、影响范围与关联关系，帮助维护者理解实施过程、识别偏差，并完成阶段验收。

这一方向仍在规划中，尚未作为产品发布。

### 产品原则

- **从具体问题出发**：每个工具聚焦一个明确的管理场景，可以独立使用。
- **以证据支持判断**：区分已知事实、推测与待确认状态，避免用看似完整的图景掩盖不确定性。
- **让人保留掌控**：清楚呈现关键决策的依据、影响和可采取的行动。
